# Microsoft Entra ID Administration Lab

## Project Overview

Built a Microsoft Entra ID administration lab using the Microsoft Azure portal. The lab focused on managing cloud user accounts, creating security groups, organising group memberships, assigning administrative roles and configuring identity settings. Practised common IT administration tasks, including password resets and reviewing audit logs to monitor directory activities and track administrative changes.

## Tools Used

- Microsoft Azure Portal
- Microsoft Entra ID
- Microsoft Entra Authentication Methods
- Microsoft Entra Audit Logs

## Tasks Completed

### 1. User Account Management

- Created and managed user accounts within Microsoft Entra ID.
- Configured and reviewed user account properties.
- Updated user profile information, including job titles.
- Practised managing user identities within a cloud directory.

### 2. Security Group Management

- Created security groups for HR, IT Support and Sales.
- Added users to the relevant security groups.
- Managed group memberships to organise users by department.
- Reviewed group membership details and directory structure.

### 3. Role-Based Access Control (RBAC)

- Explored built-in administrative roles within Microsoft Entra ID.
- Assigned the User Administrator role to a test user.
- Reviewed role assignments and directory-level permissions.
- Gained an understanding of how administrative roles control access to identity management tasks.

### 4. Password and Authentication Management

- Performed an administrative password reset for a test user.
- Reviewed Microsoft Entra authentication method policies.
- Explored Microsoft Authenticator configuration and authentication settings.
- Gained an understanding of how authentication methods support account security.

### 5. Audit Logs and Monitoring

- Reviewed Microsoft Entra audit logs to monitor directory activities.
- Identified successful administrative operations, including password resets, user updates and group membership changes.
- Reviewed role assignment events and the activities associated with administrative changes.
- Used audit logs to understand how directory changes are recorded and monitored.
